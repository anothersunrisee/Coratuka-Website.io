📄 Template QR Code untuk Cetakan Fisik

📌 Instruksi Penggunaan:

  1. 1. Generate QR code untuk masing-masing URL di bawah
  2. 2. Replace kotak ungu dengan QR code yang sudah di-generate
  3. 3. Print dengan ukuran A4 (portrait)
  4. 4. Laminating dengan bahan waterproof untuk outdoor
  5. 5. Pasang di lokasi yang sesuai dengan konteks

🖨️ Spesifikasi Cetakan:

  • • Ukuran: A4 (210 x 297 mm)
  • • Material: Vinyl sticker / PVC board
  • • Finishing: Laminating glossy waterproof

📍 Lokasi Pemasangan:

  • • Ketinggian: 1.2 - 1.5 meter dari tanah
  • • Cahaya: Hindari backlight langsung
  • • Jarak scan: 30-50 cm optimal
